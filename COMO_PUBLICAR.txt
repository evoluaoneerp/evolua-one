EVOLUA ONE v0.1.1 - PUBLICAÇÃO

1. Execute database/EVOLUA_ONE_V0.1.sql no SQL Editor do NOVO Supabase.
2. Em Supabase > Authentication > Users, crie o PRIMEIRO usuário administrador/proprietário.
3. No GitHub, repositório evolua-one, envie TODO o conteúdo desta pasta para a raiz.
4. Em Settings > Pages, publique a branch main pela pasta /(root).
5. Abra o endereço do GitHub Pages e faça login com o primeiro usuário criado.
6. No primeiro login, o sistema cria automaticamente o workspace Evolua One e define esse usuário como Proprietário.

IMPORTANTE: não crie outros usuários diretamente antes de implementarmos o convite do sistema, pois eles precisam ser vinculados ao mesmo workspace.
